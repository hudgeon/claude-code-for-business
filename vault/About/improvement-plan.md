# Improvement plan — the team's own priority list

*(Fictional worked example. From a team workshop; treat every item as a hypothesis.)*

The install's sent-mail pass (runbook B5) tests this list against the mailbox. Where the
list and the mailbox disagree, the mailbox wins — say so with numbers, not opinions.

1. Renewals correspondence takes over the office for six weeks a year.
2. Sponsorship pipeline is tracked in Robin's head and a spreadsheet.
3. CRM member data has drifted — duplicates, stale contacts, wrong categories.
4. Event run sheets are rebuilt from scratch each time.
5. Invoice chasing is ad hoc and slips when events peak.
6. Board pack assembly consumes Sam's week before each meeting.
7. Newsletter production runs late more months than not.
8. Website member directory lags the CRM by weeks.
