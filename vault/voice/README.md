# voice/ — how each person writes

Created empty on purpose: filled on install day from each person's own Sent Items
(runbook B4–B5), never from us. One `<name>.md` per person — a short paragraph on how
they write, about five real sent emails as examples (specifics swapped for
placeholders), and an explicit line saying which of the *other* people's rules this file
does **not** inherit. Rule bleed is the failure mode of a shared folder.

Also created here as needed: `signatures/<name>.md` (the text signature lifted from a
real sent email — every draft carries it) and `drafts/` (every draft is stashed the
moment it is created; exactly one live draft per email).
